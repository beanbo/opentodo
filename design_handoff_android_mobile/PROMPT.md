# Промт для Claude Code

Скопируй текст ниже в Claude Code, запущенный в корне репозитория OpenTodo. Папку `design_handoff_android_mobile/` положи внутрь репозитория (или укажи путь).

---

Ты работаешь в репозитории **OpenTodo** — десктоп/мобильный таск-менеджер на **Qt 6 (QML, Quick Controls Material)** с C++ вью-моделями. Нужно реализовать **мобильный Android-редизайн**. В папке `design_handoff_android_mobile/` лежит дизайн-референс (интерактивный HTML/React-прототип) и `README.md` с полной спецификацией — прочитай README целиком перед началом.

**Важно:** HTML/JSX — это **референс внешнего вида и поведения**, а не код для переноса. Реализуй всё нативно в QML, используя существующие паттерны проекта: синглтоны `ThemeManager`/`Spacing`/`FontSize`/`Radius`/`Duration`, компонент `IconSvg`, вью-модели (`taskViewModel`, `sidebarViewModel`, `projectViewModel`, `searchViewModel`, `settingsViewModel`, `notificationService`). Не подключай React и не копируй inline-стили — переводи их в QML-свойства и токены.

**Перед кодом:** изучи текущие `qml/layouts/MobileLayout.qml`, `qml/components/TaskItem.qml`, `QuickAdd.qml`, `TaskEditor.qml`, `SidebarContent.qml`, `qml/themes/*`, `qml/views/*`. Сверься с README (раздел «Точка входа в кодовую базу»). Сохрани существующую архитектуру и русскоязычные строки.

**Объём (делай инкрементально, по одному PR-сайз блоку, с проверкой сборки после каждого):**
1. **Нижняя навигация** в `MobileLayout.qml`: «Входящие» + до 3 закреплённых слотов (**проект или умный список** — Сегодня/Предстоящие) + плавающий FAB. Закрепление — булавкой в `SidebarContent` и долгим нажатием по слоту (bottom-sheet с группами «Умные списки»/«Проекты», лимит 3, persisted в QSettings). Подписи вкладок — короткий алиас проекта. Скрывать навбар/FAB в режиме мультивыбора.
2. **Свайпы в `TaskItem`**: вправо — выполнить, влево — Отложить/Удалить (пороги и подложки из README). Корректно различать горизонтальный жест и вертикальный скролл.
3. **Undo-снэкбар** (4.2с) для выполнить/удалить/отложить и массовых действий — снимок состояния до мутации.
4. **Долгое нажатие (480ms) → контекст-меню** задачи (bottom-sheet) и **режим мультивыбора** с тулбаром массовых действий (выполнить/переместить/удалить).
5. **Полноэкранный редактор**: рабочие листы-пикеры (срок+календарь, приоритет, проект, метки-мультивыбор, повтор, напоминание), секции комментариев и истории изменений.
6. **Quick-add**: компактное поле над клавиатурой с реальным вводом и чипами (срок/приоритет/проект/метка), создание задачи.
7. **Новые/дореализованные экраны**: Календарь-месяц (сегмент проекта), Уведомления, Продуктивность, Корзина, Метки, Фильтры — подключить в drawer и роутинг (`isFullPageView`/`fullPageLoader` в `MobileLayout`).
8. **Настройки**: сетка из 9 палитр + кастомный акцент (`ThemeManager.customAccentHex`), плотность, «Высокий контраст» и «Крупный шрифт».
9. **Полировка**: пустые состояния по видам, сжимающийся app bar при скролле, тач-таргеты ≥ 48 dp, расширить `handleBack()` под новые оверлеи, уважать `prefers-reduced-motion`.

**Требования к качеству:** все интерактивные элементы ≥ 48 dp; цвета только из `ThemeManager` (никаких хардкод-хексов в компонентах); иконки через `IconSvg` (имена — в README; новых не рисовать); строки — через `qsTr`. После каждого блока: собрать (`cmake`/`qmake` как в проекте), прогнать приложение в мобильном лейауте, проверить тёмную и светлую темы.

Начни с того, что выведи краткий план реализации и список файлов, которые будешь менять/создавать, затем приступай к блоку 1.
