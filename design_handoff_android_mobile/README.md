# Handoff: OpenTodo — мобильный Android-редизайн

## Overview
Полный редизайн мобильного клиента OpenTodo (Qt 6 / QML) под Android. Цель — заменить «ужатый десктоп» на нативно-ощущаемый мобильный интерфейс: крупные тач-зоны (≥ 48 dp), нижняя навигация с закреплёнными проектами, свайп-жесты по задачам, Undo, компактный quick-add, рабочие пикеры, мультивыбор и несколько новых экранов.

## About the Design Files
Файлы в этом бандле — **дизайн-референс, собранный в HTML/React** (интерактивный прототип, показывающий внешний вид и поведение). Это **не** продакшен-код для копирования. Задача — **воссоздать эти экраны в существующей кодовой базе OpenTodo на QML (Qt 6 Quick / Controls Material)**, используя её паттерны: синглтоны `ThemeManager`, `Spacing`, `FontSize`, `Radius`, `Duration`; компонент `IconSvg` (tint по `currentColor`); вью-модели (`taskViewModel`, `sidebarViewModel`, `projectViewModel`, `searchViewModel`, `settingsViewModel`, `notificationService`).

Прототип написан на React только ради скорости итерации — переносить логику нужно в QML.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, радиусы, тайминги и поведение заданы точно. Иконки уже существуют как stroke-SVG в `resources/icons/ui/` и рендерятся через `IconSvg`. Палитры уже есть в `ThemeManager.qml`. Воссоздавать пиксель-в-пиксель средствами QML.

## Точка входа в кодовую базу
- Шелл мобильного: `qml/layouts/MobileLayout.qml` — здесь верхняя панель, тело, **новая нижняя навигация**, FAB, drawer (`Drawer` + `SidebarContent.qml`), полноэкранный редактор (`StackView`), оверлей поиска. Сюда же добавляются: снэкбар, контекст-меню, листы-пикеры, режим мультивыбора.
- Строка задачи: `qml/components/TaskItem.qml` — добавить свайпы и режим выбора.
- Быстрый ввод: `qml/components/QuickAdd.qml`.
- Редактор: `qml/components/TaskEditor.qml` + `qml/components/editor/*`.
- Сайдбар/навигация: `qml/components/SidebarContent.qml`.
- Темы/токены: `qml/themes/ThemeManager.qml`, `Spacing.qml`, `FontSize.qml`, `Radius.qml`, `Duration.qml`.
- Вьюхи: `qml/views/{CalendarView,NotificationsView,ProductivityView,TrashView,SettingsView}.qml`.

### Размеры / тач-зоны
- Нижняя навигация: высота **66**; иконка 21; активный «pill» за иконкой 56×30, радиус 16; подпись 11.5 (max-width 88, ellipsis; для проектов использовать короткий алиас `short`).
- Верхняя панель: 56 (компактная) / большой заголовок 27px ниже строки иконок.
- FAB: 60×60, радиус 19 (M3 squircle); иконка 27; тень.
- Иконка-кнопка (тап-таргет): 46×46, радиус 23.
- Bottom-sheet: радиус верхних углов 22; «грабли» (drag handle) 36×4.
- Drawer: ширина 308.

### Тайминги
- Свайп-порог «выполнить» (вправо): сдвиг > **92px**.
- Свайп-порог «экшены» (влево): < **−84px**, фиксируется на **−156px** (две кнопки: Отложить ≈78px, Удалить 78px).
- Долгое нажатие (контекст-меню/выбор): **480ms**, отменяется при сдвиге > 6px.
- Снэкбар: авто-скрытие **4200ms**, slide-up `transform .28s cubic-bezier(.2,.8,.2,1)`.
- Drawer/sheet/редактор: `.3s cubic-bezier(.2,.8,.2,1)`; редактор — slide-up снизу.
- Pop-анимация при смене закреплённого проекта в навбаре: `scale .34s cubic-bezier(.2,.9,.3,1.2)` (0.62→1.06→1).

### Цвета — берутся из ThemeManager (уже реализованы). Ключевые (dark / classic_light):
- bg `#1f1f1f` / `#f6f6f4`; surface `#282828` / `#ffffff`; card `#303030` / `#ffffff`
- text `#ededed` / `#1d1d1d`; secondary `#9a9a9a` / `#7a7a78`; border `#363636` / `#e7e7e2`
- accent `#e2574b` (dark) / `#db4c3f` (light); accentForeground `#ffffff` (на жёлтом/высоком контрасте — тёмный)
- accentContainer (тональный фон активной навигации/чипа) `#3a2320` / `#ffe7e2`
- priority P1 `#e05050` · P2 `#eb8909` · P3 `#3d82e0`/`#2070d8` · P4 `#7d7d7d`
- success `#4caf50` · warning `#eb9b18` · error `#e05050`
- **9 палитр**: classic_light, dark, graphite, kale, blueberry, lavender, raspberry, sunflower, highcontrast — все уже в `ThemeManager.qml`.
- **Кастомный акцент**: 10 swatches (`#db4c3f #e2574b #e8702a #eaa72a #3aa84e #2c9c8e #2070d8 #6c88f4 #9b5de5 #e0608a`) → пишется в `ThemeManager.customAccentHex` (механизм уже есть).

## Screens / Views

### 1. Нижняя навигация (главное изменение)
4 слота + плавающий FAB справа:
- **Слот 1 — «Входящие»** (фикс). Иконка `inbox`. Активна на экране Inbox.
- **Слоты 2–4 — закреплённые слоты** (до 3): проект **или умный список** (Сегодня / Предстоящие). Иконка и короткое имя (`short`-алиас проекта). Активны на соответствующем экране. Дефолт: Сегодня + 2 проекта.
- Пустой слот: пунктирная рамка + «Закрепить» → открывает лист управления.
- **Закрепление**: булавка в каждой строке проекта в drawer (`SidebarContent`), И **долгое нажатие** по слоту навбара → bottom-sheet «Закреплённое в нижней панели» с двумя группами: «Умные списки» (Сегодня, Предстоящие) и «Проекты» (тумблеры-булавки, лимит 3; 4-й вытесняет самый старый, нумерация №1–3).
- FAB: открывает quick-add. В режиме мультивыбора навбар и FAB скрыты.
- Поиск, Сегодня, Предстоящие, Помощник, Настройки и новые экраны — в drawer и/или в верхней панели (иконка поиска).

### 2. Список задач (Inbox / Today / Upcoming / Project)
- Большой заголовок с иконкой+цветом, подзаголовок (дата / число задач). **Сжимается** в компактную 56-строку при скролле (scrollTop > 24).
- Для проекта — сегмент-переключатель **Список / Доска / Календарь** (M3 segmented).
- Секции (сворачиваемые): напр. «Просрочено», «Сегодня».
- Строка задачи (`TaskItem`): шеврон подзадач (декоративный/кликабельный), круглый чекбокс с цветом приоритета, заголовок (2 строки, ellipsis), ряд мета-чипов (повтор, дата с иконкой календаря, дедлайн-флаг, прогресс подзадач N/M, метки с цветом, проект), тонкий прогресс-бар подзадач.
- **Цвет чипа даты**: просрочено → error (красный), сегодня → **success (зелёный)**, завтра/скоро → warning/P2 (оранжевый), дальше → secondary. Красный зарезервирован за просрочкой — «Сегодня» НЕ красить акцентом (в тёмной теме акцент и error почти неразличимы).
- **Свайпы**: вправо → выполнить (зелёная подложка с галочкой и «Выполнить»); влево → раскрыть «Отложить» (warning) + «Удалить» (error). Распознавание оси: горизонталь, если |dx|>|dy| и |dx|>6; `touch-action: pan-y` для сохранения вертикального скролла.
- **Пустые состояния** — свои на каждый вид (иконка+заголовок+текст).
- **Долгое нажатие** → контекст-меню задачи.

### 3. Мультивыбор
- Вход: долгое нажатие → пункт «Выделить несколько» (или сразу выбор). Верхняя панель меняется на тулбар выбора: «×», «N выбрано», действия: Выполнить, Переместить (папка), Удалить.
- В строках чекбокс становится кружком-выбором; тап переключает выбор (свайпы и открытие отключены).
- Массовые действия показывают Undo-снэкбар.

### 4. Контекст-меню задачи (bottom-sheet)
Превью задачи + действия: Открыть, Выполнить/Снять, Выделить несколько, Переместить в проект, Дублировать, Удалить (красный).

### 5. Полноэкранный редактор задачи
- Тулбар: закрыть (шеврон-вниз), флаг приоритета, закрепить, ещё.
- Заголовок + крупный чекбокс + описание.
- **Свойства-строки (открывают листы-пикеры)**: Срок (быстрые чипы Сегодня/Завтра/Выходные/Без срока + календарь-месяц), Приоритет (P1–P4), Проект, Метки (мультивыбор), Повтор (правила), Напоминание (Без / в момент / за 10 мин / за 1 ч / за день / своё).
- Подзадачи: прогресс, чек-строки, кнопка AI-разбивки, «+ Добавить».
- **Комментарии**: список с аватарами (инициалы; AI-аватар акцентный) + поле ввода.
- **История изменений** (сворачиваемая): таймлайн событий.
- Нижняя панель быстрых действий (те же пикеры).

### 6. Быстрое добавление (quick-add)
- Лист снизу над клавиатурой: круглый чекбокс приоритета, **реальное поле ввода** (autofocus), кнопка отправки (активна при непустом тексте).
- Ряд чипов (тап циклически меняет значение): Срок (Сегодня→Завтра→нет), Приоритет (P4→P1), Проект (циклом), Метка (вкл/выкл). Активный чип тонирован своим цветом.
- Отправка создаёт задачу во «Входящих» (по умолчанию проект OpenTodo) и показывает снэкбар.

### 7. Доска (Kanban)
Горизонтальные колонки (ширина 280) со scroll-snap; карточки: чекбокс, заголовок, мета-чипы; кнопка «+ Добавить»; «+» в шапке колонки.

### 8. Календарь-месяц
Шапка «<Месяц> <Год>» + рабочие ‹ › (листание месяцев, переход через год); сетка Пн–Вс; день = число (кружок: сегодня — тональный, выбранный — заливка акцентом) + до 3 точек цветами приоритета задач этого дня; ниже — список задач выбранного дня.

### 9. Уведомления
Список: цветная иконка-плитка (просрочка/напоминание/AI/выполнено), заголовок, тело, время, точка непрочитанного; тап → открыть задачу; «прочитать все» в шапке.

### 10. Продуктивность
Карточки: серия (огонёк + N дней), кольцо дня (conic-gradient %, N/M), недельный бар-чарт (7 столбцов, цель = полный акцент, ниже цели — полупрозрачный), карма+уровень с прогресс-баром.

### 11. Корзина
Список удалённых (зачёркнуто, проект + «удалено …») + кнопка «Восстановить»; «Очистить» в шапке; примечание про авто-очистку 30 дней.

### 12. Метки / Фильтры
Метки: цветная плитка + название + счётчик. Фильтры: плитка + название + query (моноширинный) + счётчик.

### 13. Настройки
- **Оформление**: сетка из 9 палитр (3 кол.) с превью; ряд из 10 акцентных swatches; сегмент плотности.
- **Доступность**: «Крупный шрифт» (масштаб ~1.1; в QML — увеличить базовый `FontSize`/`Text.fontSizeMode`), «Высокий контраст» (палитра `highcontrast`).
- **Уведомления и данные**: пуш, синхронизация, AI (тумблеры → `settingsViewModel`).
- **Прочее**: поддержать разработчика, о приложении.

## Interactions & Behavior (сводка)
- Свайп-жесты, долгое нажатие, мультивыбор, Undo-снэкбар, листы-пикеры, сжимающийся app bar, pop-анимация навбара — тайминги и пороги см. в «Design Tokens».
- Back-кнопка Android: закрыть редактор → закрыть поиск/лист → закрыть drawer → выйти из мультивыбора → навигация на Inbox → выход (логика уже частично есть в `MobileLayout.handleBack()` — расширить под новые оверлеи).
- Анимации входа слайдов: базовое состояние — видимое; гейтить «появление из скрытого» на активном экране и `prefers-reduced-motion`.

## State Management (привязки к существующим вью-моделям)
- Задачи: `taskViewModel` (complete/uncomplete/update/delete/openTaskById, filterMode). Undo — снимок до мутации, повторная вставка по «Отменить».
- Закреплённые проекты: новое persisted-состояние (QSettings, категория напр. `bottomNavPins`, до 3 id).
- Навигация/проекты/метки/фильтры: `sidebarViewModel`, `projectViewModel`, `filterViewModel`, `searchViewModel`.
- Тема/акцент/плотность/шрифт: `settingsViewModel` + `ThemeManager` (`customAccentHex`, `compactDensity`).
- Напоминания: `notificationService.scheduleNotification`.

## Assets
- Иконки: уже есть stroke-SVG в `resources/icons/ui/` (рендер через `IconSvg`, tint `currentColor`). Имена в прототипе совпадают с набором (`inbox, today, upcoming, calendar, search, menu, plus, check, chevron-*, flag, tag, repeat, alarm, pin, trash, bell, sparkles, settings, flame, star, board, list, folder, note, send, sync, reset` и т.д.). Новых рисовать не нужно — при нехватке сохранить в том же стиле (24×24, stroke `currentColor`, `stroke-linecap/linejoin: round`).
- Изображений/растровых ассетов нет.

## Files (дизайн-референс в этом бандле)
- `OpenTodo Android.html` — точка входа: design-canvas со всеми экранами + Tweaks (тема/плотность). Открыть в браузере.
- `m-tokens.jsx` — палитры (9), плотность, акценты, helpers.
- `m-data.jsx` — демо-данные (структуры задач/проектов/уведомлений/продуктивности).
- `m-components.jsx` — `MTaskRow` (свайпы+выбор), чекбокс, чипы, секция, FAB, сегмент, bottom-sheet.
- `m-pickers.jsx` — снэкбар, опшен-лист, календарь-месяц, контекст-меню.
- `m-screens.jsx` — список, верхняя панель, drawer, доска.
- `m-screens2.jsx` — редактор, quick-add, поиск, настройки, клавиатура.
- `m-screens3.jsx` — календарь, уведомления, продуктивность, корзина, метки, фильтры.
- `m-app.jsx` — оболочка: роутинг, нижняя навигация, оверлеи, состояние.
- `icons.jsx` — stroke-иконпак (соответствие `IconSvg`).
- `android-frame.jsx`, `design-canvas.jsx`, `tweaks-panel.jsx` — каркас прототипа (для реализации не нужны, только для просмотра).

> Запуск референса: открыть `OpenTodo Android.html` в браузере. Каждый «телефон» кликабелен; в режиме фокуса (по клику на артборд) жесты и переходы работают корректно. Панель Tweaks меняет тему/плотность на всех макетах.
